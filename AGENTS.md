# Agent Plugins

Shared dev-team prompts live in `shared/dev-team/`; host metadata lives in `adapters/`.
`plugins/`, `.agents/plugins/marketplace.json` and `.claude-plugin/marketplace.json`
are generated by `python3 scripts/build.py`. Edit their sources and regenerate.

Use Python 3.11+ and the standard library. Validate with:

```sh
python3 scripts/build.py --check
python3 scripts/check_skill_metadata.py
python3 -m unittest discover -s tests -v
```

Keep plugin packages self-contained. Do not create links outside a plugin root.
Do not make plugin installation silently change permissions, auth, unrelated agent
files or external services. Test installers with temporary project directories.

After initial bootstrap, use signed Conventional Commits on a branch and open a
GitHub PR with `gh`; do not merge unless asked. Independently review changes to
scripts or agent behavior. Keep generated outputs synchronized with sources.
